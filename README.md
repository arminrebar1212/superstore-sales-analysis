# 🛒 Superstore Sales Analysis

A complete exploratory data analysis (EDA) project on 4 years of US retail sales data (2014–2017).  
Built with Python, Pandas, Matplotlib, and Seaborn.

---

## 📌 Project Overview

This project analyzes **9,994 sales transactions** from a US retail superstore to uncover insights about profitability, regional performance, customer behavior, and the impact of discounting.

It covers the full data workflow:
- Raw data ingestion & cleaning
- Feature engineering
- Exploratory data analysis
- Data visualization

## 📊 Dataset

|---|---|

| Rows | 9,994 orders |
| Columns | 21 (raw) → 27 (after feature engineering) |
| Period | January 2014 – December 2017 |
| Region | United States |

---

## 🧹 Data Cleaning (`src/clean_data.py`)

- Standardized all column names (lowercase, underscores)
- Converted `order_date` and `ship_date` to datetime
- Added 7 derived columns:
  - `order_year`, `order_month`, `order_quarter`
  - `shipping_days` — days between order and shipment
  - `profit_margin` — profit as % of sales
  - `revenue_per_unit` — sales divided by quantity
  - `is_unprofitable` — flags orders with negative profit

## 🔍 Key Findings

### 1. Sales Are Growing Year Over Year
Sales show a clear upward trend from 2014 to 2017, with consistent Q4 spikes every year driven by holiday demand.

### 2. Technology Is the Most Profitable Category
| Category | Total Profit |
|---|---|
| Technology | $145,455 |
| Office Supplies | $122,490 |
| Furniture | $18,451 |

### 3. The West Region Leads in Both Sales and Profit
| Region | Sales | Profit |
|---|---|---|
| West | $725,458 | $108,418 |
| East | $678,781 | $91,522 |
| Central | $501,240 | $39,706 |
| South | $391,722 | $46,749 |

### 4. Discounting Destroys Profit
Orders with **0% discount** generate the highest profits (up to $8,000 per order).  
Orders with **40%+ discount** are almost entirely unprofitable.  
**18.7% of all orders (1,871 orders) operate at a loss.**

### 5. Copiers Are the #1 Most Profitable Sub-Category
| Rank | Sub-Category | Profit |
|---|---|---|
| 1 | Copiers | $55,618 |
| 2 | Phones | $44,516 |
| 3 | Accessories | $41,937 |

### 6. Consumers Drive Half of All Revenue
| Segment | Sales | Share |
|---|---|---|
| Consumer | $1,161,401 | 50.6% |
| Corporate | $706,146 | 30.7% |
| Home Office | $429,653 | 18.7% |

## ▶️ How to Run

1. Clone the repository:
```bash
git clone https://github.com/arminr47/superstore-sales-analysis.git
cd superstore-sales-analysis
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Run the cleaning script:
```bash
python src/clean_data.py
```

4. Open the notebook:
```bash
jupyter notebook notebooks/analysis.ipynb
```
